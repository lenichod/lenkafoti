Connect your photo manager

The editor is ready to use with your GitHub Pages repository. Publishing stays locked until you connect that repository with a GitHub access key. This is a GitHub credential, rather than a separate website password.

  1. Create your website repository on GitHub (suggested: lenichod/lenkafoti) and upload the extracted website package. The repository root must contain index.html, gallery-data.js, photos/ and admin/. This version of the editor uses a public repository.
  2. Enable GitHub Pages for the branch you use, usually main, and its root folder. Custom-domain setup for lenkafoti.cz is described in the package README.
  3. Open GitHub’s fine-grained access-token settings. Select your account as the resource owner, choose Only select repositories and your website repository, then grant Repository permissions → Contents → Read and write. Set an expiry you are comfortable with. Metadata read access is included automatically; no other permissions are needed.
  4. Copy the generated key into the photo manager’s password-style GitHub access key field. Do not put it in website files or send it in chat. Enter the repository and branch, then select Connect securely.

Your everyday routine

Open /admin/, connect, and use Add photos. The editor resizes JPEG, PNG and WebP images for you. Add an English and Czech description, tick the collections, move photos into the order you want, and select the three Home photographs. Choose Save to GitHub when you are ready. GitHub Pages then publishes the commit when it is enabled for that branch.

You can try these controls with Try the editor without publishing. Preview changes are temporary and are not saved. The private ChatGPT preview and the GitHub website are separate: saving in the manager updates GitHub only.

Access and recovery

The editor has no link in the public navigation. Its route and interface can be viewed, but GitHub enforces permission for every write. The key lives only in the open tab’s memory; sign out or close the tab to clear it. Use a key scoped only to your website repository, and revoke it in GitHub settings if you lose it.

Unsaved changes remain in the current tab. Reloading or signing out asks before discarding them. If another person edits the repository, the manager refuses to overwrite their changes. Removing a photo takes it out of the portfolio; source images and GitHub history remain. Uploading strips original metadata by re-encoding the image. Avoid committing credentials to any file.

Připojení správce fotografií

Editor je připravený pro repozitář tvého webu na GitHub Pages. Ukládání se odemkne až po připojení pomocí přístupového klíče GitHubu. Používá přihlašovací údaj GitHubu, nikoli samostatné heslo webu.

  1. Vytvoř repozitář webu (doporučený název: lenichod/lenkafoti) a nahraj obsah rozbaleného balíčku. Soubory index.html, gallery-data.js a složky photos/ a admin/ musí být přímo v kořeni repozitáře. Tato verze editoru používá veřejný repozitář.
  2. Zapni GitHub Pages pro svou větev (obvykle main) a kořenovou složku. Připojení lenkafoti.cz je popsané v README balíčku.
  3. V nastavení klíčů GitHubu vytvoř fine-grained personal access token. Vyber svůj účet jako vlastníka, Only select repositories a repozitář webu. Nastav Repository permissions → Contents → Read and write a vhodnou platnost. Čtení metadat je automatické; další oprávnění nejsou potřeba.
  4. Vygenerovaný klíč vlož do pole Přístupový klíč GitHubu ve správci. Nevkládej ho do souborů webu ani neposílej do chatu. Zadej repozitář a větev a klikni na Bezpečně připojit.

Běžné používání

Otevři /admin/, připoj GitHub a klikni na Přidat fotografie. Editor obrázky JPEG, PNG a WebP sám zmenší. Doplň anglický a český popis, vyber kolekce, uprav pořadí a tři fotografie na úvodní stránce. Pak klikni na Uložit na GitHub. Pokud je pro danou větev zapnuté Pages, GitHub následně publikuje změny.

Tlačítkem Vyzkoušet editor bez publikování si ovládání vyzkoušíš nanečisto. Úpravy v náhledu jsou dočasné. Soukromý náhled v ChatGPT a web na GitHubu jsou oddělené — ukládání aktualizuje pouze GitHub.

Přístup a obnovení

Editor nemá odkaz ve veřejném menu. Jeho rozhraní lze otevřít, ale každé ukládání chrání oprávnění GitHubu. Klíč zůstává jen v paměti otevřené karty; odhlášení nebo zavření ho smaže. Omez ho pouze na repozitář svého webu. Při ztrátě ho zruš v nastavení GitHubu.

Neuložené úpravy zůstávají v aktuální kartě. Před jejich zahozením se editor zeptá. Změny jiného editora nepřepíše. Odebrání fotografie ji odstraní z portfolia, ale soubory a historie GitHubu zůstanou zachovány. Nové fotografie se převádějí bez původních metadat. Přístupové klíče neukládej do souborů.
